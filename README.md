# ttaV8.8.0 — 电子课程表（整合 exam 显示 + 显示时间）

由 `lchV8.3.0_ttaV8.5.0_merged`（主程序）整合 `源.cpp`（ExamDisplay，考试显示）而来。
单文件程序：全部代码都在 `ttaV8.8.0.cpp` 里。

## 打开方式

- 首选：双击 `ttaV8.8.0.slnx`，用 Visual Studio 2026 打开。
- 备用：如果你的 VS 打不开 `.slnx`，双击 `ttaV8.8.0.sln`（传统格式，内容同一个工程）。
- 平台选 **x64**，配置先用 **Debug**，生成 → 生成解决方案。
- 如果 VS 提示“工具集 v145 不可用 / 需要重定目标”，点“重定目标”接受即可（平台工具集以你本机 VS2026 自带的为准，不影响代码）。
- 生成的 exe 在 `x64\Debug\ttaV8.8.0.exe`（Release 同理）。

也可以直接用命令行编译（在“x64 Native Tools Command Prompt for VS 2026”里）：

```
cl /utf-8 /EHsc /std:c++17 ttaV8.8.0.cpp /link user32.lib gdi32.lib shell32.lib comctl32.lib dwmapi.lib
```

## 相对上一版新增的功能

1. **考试窗口（exam 行）**
   - 课程文件里某一行以 `exam` 开头时，按考试显示处理，见 `CSV格式说明.md`。
   - 考试窗口在考前 20 分钟出现，考试结束 5 分钟后自动隐藏；其它时间不显示。
   - 考试窗口显示时，主窗口和子窗口自动隐藏；考试窗口隐藏后，主/子窗口按原来的规则恢复。
   - 点“关闭课表”时，主窗口、子窗口、考试窗口一起关闭（隐藏）。
   - 考试窗口右上角有关闭按钮：手动关闭只对本场考试有效，本场内不会再自动弹出来；下一场考试照常显示。
   - 相对源程序修掉的毛病：①“本场考试还有15分钟结束”原来只显示 1 分钟，现在是结束前 15 分钟整段显示；②考试结束后不再退出整个程序，只隐藏考试窗口；③排版按窗口高度比例缩放，换屏幕不跑偏；④不再另读 `timetable_*.txt` 的 `mode:exam` 旧格式，统一走 CSV。
2. **显示时间按钮**
   - 课程表控制中心最下面第二行第一格（`status` 按钮左边那个空位）加了“显示时间”按钮。
   - 点一下打开一个大窗口，全屏显示当前时间（精确到秒），上面还有日期和星期；标准 Windows 窗口，可以关闭、最小化、最大化、拖动、缩放。
   - 时间窗口开着的时候，按钮变成“关闭时间”，再点一下就关掉它；也可以直接点时间窗口自己的关闭按钮。
   - 时间窗口和课表主/子窗口、考试窗口相互独立：点“关闭课表”不影响它，控制中心关了也不影响它；只有从托盘退出整个程序时它才会跟着关。
   - 注意：时间窗口显示的是真实本地时间，不加控制中心里的“矫正秒数”；考试窗口用的则是含矫正秒数的课表时间，和主/子窗口保持一致。

## 原有功能（都没动）

U盘监听、主/子窗口显示规则、午休黑屏、控制中心（主/子模式、黑屏开关、U盘自启、矫正计时、启动/关闭课表、status 管理）、定时关机、托盘菜单、课程修改器联动。

## 课程文件放在哪

`D:\Timetable\Sources\`，格式见 `CSV格式说明.md`，示例见 `示例课程文件\`（复制过去改名使用，不要直接把示例文件当正式课表用）。

## 在 Windows 上拿到后第一步

1. 解压后双击 `ttaV8.8.0.slnx`，选 x64 / Debug，生成。
2. 把 `示例课程文件\timetable_2026-11-18.csv` 复制到 `D:\Timetable\Sources\`，按实际考试科目和时间改好里面的 `exam` 行。
3. 运行 exe，托盘点控制中心，验证“显示时间”按钮和 `status` 按钮都在最下面一行。
4. 把系统时间临时调到某场考试开始前 20 分钟内（或直接把示例 exam 行的开始时间改成当前时间之后 10 分钟），看考试窗口是否出现、主/子窗口是否隐藏；等开始时间过了再看倒计时是否正常走。
